# Contributing to XG Capital Strategies repositories

All human and AI contributors should follow the organization [Agentic Git Governance policy](docs/AGENTIC_GIT_HYGIENE.md). Inspect existing issues, active PRs, source SHA and branch lineage before creating new work. Continue the current issue branch where possible. For truly independent work, create a scoped sub-issue with owner, file-path responsibility and explicit dependencies.

Use issue-scoped names (for example feature/gh-123-brief-scope), source-pinned test evidence and explicit cleanup/retention intent. Never bulk-close or prune based on age or apparent redundancy. Preserve production/research holds and credentials. Repo-local AGENTS.md and release-specific controls take precedence.

This fallback document is guidance until a specific repository has adopted it and its technical restrictions have been independently verified.
